# 🧠 BrainBuzz - Quiz Website

🎮 A simple and interactive Quiz Website built using HTML, CSS, and JavaScript.

---

## 🚀 About the Project

BrainBuzz is an online quiz platform where users can test their knowledge by choosing different difficulty levels.  
The website contains multiple-choice questions and displays the final score along with the correct answers after submission.

---

## 🎯 Features

📚 **Three Difficulty Levels**  
- Easy  
- Medium  
- Difficult  

📝 **Multiple Choice Questions**  
- Users can answer quiz questions interactively  

✅ **Instant Score Calculation**  
- Automatically calculates marks after submission  

💡 **Correct Answer Display**  
- Shows correct answers after completing the quiz  

🎨 **Simple User Interface**  
- Clean and beginner-friendly design  

⚡ **Interactive Quiz Experience**  
- Smooth navigation and responsive buttons  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript
